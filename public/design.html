为什么这样设计

所有图形均为本项目原创绘制（SVG/CSS），不使用任何外部图片素材；色彩、纹样与版式都来自非遗竹编这一主题本身。

一、色彩：从器物中取色

竹青 #3F6B53

新竹表皮与“留青收口”，作主色/确认态。

竹黄 #C4A15F

去青后的竹黄篾，用于高亮与候补/保留态。

朱砂印 #8C3A2B

题落款印章色，用于关键动作、撤回/到期警示。

宣纸 #F6F0E2

背景底色，叠加 CSS 生成的纤维纹理。

墨 #2F2A20

正文文字，取松烟墨色。

编纹

六角编 pattern 用于分隔带与占位锁定纹理。

三、信息架构与状态语义

技艺故事页是中心：传承人 → 作品 → 材料 → 展示/教学两版步骤 → 相关课次 → 发布版本，一屏串联。

两类不可用使用两种颜色与图标，避免用户混淆：

  • 席位问题 容量满、占位超时、改期/取消、管理员减容量 → 黄色提示条 🎟️，引导候补/改报。
  • 内容问题 撤回许可、授权到期、未授权 → 朱砂提示条 🚫/⏳，说明素材下架但记录保留。

状态色统一：确认=竹青、短暂保留/候补=竹黄、撤回/过期/取消=朱砂/灰。全站徽标一致。

四、关键交互设计

短暂保留 + 倒计时

报名成功即出现以服务端过期时间为准的倒计时；到点前端不自行判定成败，而是重新轮询订单，避免时钟偏差。

候补顺序可视化

候补中显示排队位置，4 秒轮询；被晋升为保留时自动切换到倒计时，全流程可感知。

断网不重复报

顶部断网站标 + 本地保存报名信息 + 固定幂等键自动重试；服务端同键返回原单（retried=true）。

改期可追溯

订单同时显示“报名时快照时间”和“当前排期时间/版本”，出现“已改期”徽标并允许免费取消。

五、技术取舍

采用 预约保留（hold-then-confirm）而非实时扣减：数据库 SELECT … FOR UPDATE 锁定课次行后在同一事务内统计 held + confirmed，再决定“保留 / 候补”，因此并发下绝不超卖；超时由后台 sweeper 与请求事务双重回收， 回收后按 waitlist_seq 用 FOR UPDATE SKIP LOCKED 顺序晋升候补。

持久化全部落在 PostgreSQL：订单状态机、订单事件、发布版本（作品换图/步骤修订/改期/容量变更）、审计日志。撤回授权仅更新许可行，不删除任何课程记录。

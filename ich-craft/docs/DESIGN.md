# 站内设计依据（Design Rationale）

## 1. 视觉从材料里取色，不从流行色板取色

| 色彩 | 色值 | 出处 |
| --- | --- | --- |
| 生丝/米纸底 | `#f7f1e4` | 宣纸、未染棉布的本色，做大面积留白 |
| 朱砂红 | `#c0392b` / `#8c2f23` | 剪纸红纸、印章印泥，用于主行动与品牌 |
| 靛蓝 | `#1d3a5c` / `#2f5d8a` | 板蓝根冷染的扎染蓝，用于信息、链接 |
| 竹青 | `#5d7c4a` | 慈竹刮青后的竹色，少量点缀 |
| 鎏金黄 | `#c9a15b` | 剪纸描金、竹篾高光，分隔线与焦点 |

全站只在「语义状态色」上引入另外四色：成功绿、警告黄、危险红、信息蓝，
并与上面的主色保持明度一致，避免廉价感。

## 2. 字体：一块匾、一行字

- 标题用**宋体**（Songti/STSong/Noto Serif SC），呼应谱牒、匾额、窗花衬底的雕版气质。
- 正文用**无衬线**（PingFang/Noto Sans），保证步骤说明、报名倒计时的屏幕可读性。
- 字距标题 +0.04em，正文行高 1.7，对齐传统版式「疏可走马」。

## 3. 原创视觉清单（无外链、无版权图）

所有图均为手工 SVG，位于 `public/assets/`：

- `hero.svg`：剪纸圆牌、扎染染缸与晾晒方巾、竹编簸箕与篾片，同框交代三项技艺
- `logo.svg`：印章圆牌 + 四瓣花 + 穿心篾，呼应「守艺」
- `paper-cut.svg / tie-dye.svg / bamboo.svg`：三项技艺的作品主视觉
- `pc-step*.svg / td-step*.svg / bb-step*.svg`：六个教学步骤插图
- `hero.svg` 同时作为「作品换图」验收的替换图

## 4. 版式与组件

- 最大宽度 1080px，间距取 8px 网格（卡片圆角 10、阴影低对比、细 1px 描边）。
- 故事页采用 1.7:1 双栏（主体/侧栏），材料与传承人放侧栏，步骤用「图 + 文」横排。
- 席位用**数字药丸**（seat-pill）给出一眼可读的剩余量：绿=可报，红=已满。
- **两类不可用必须视觉分开**：
  - 席位原因 → 黄色 notice（保留中/候补/超时/减容量）
  - 内容原因 → 暗红 notice（授权未生效/撤回/到期）
  这对应后端两组完全不重叠的错误码（见 docs/API.md）。

## 5. 交互中的可信反馈

- 报名后用「提交 → 保留中（倒计时）→ 确认」流程条把预约保留模型画出来。
- 断网时顶部出现离线横幅，操作进发件箱；恢复在线自动重放并提示「不会重复报名」。
- 我的报名里，改期记录同时显示「报名时的时间」与「当前时间」，让改期可核验而不是覆盖。
- 管理后台减容量时， toast 明确报告「挤出几个占位、递补几个人」。

## 6. 可访问性与响应式

- 所有 SVG 带 `role="img"` 与中文 `aria-label`；色彩对比度满足正文阅读。
- 860px / 680px / 560px 三个断点：故事双栏→单栏，步骤横排→竖排，课次双列→单列。
- 不依赖鼠标：按钮为原生 `<button>`，表单 label 关联。
